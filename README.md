# harness-lab

Мій робочий репо для проходження курсу
[walkinglabs/learn-harness-engineering](https://github.com/walkinglabs/learn-harness-engineering)
(MIT, див. `LICENSE-course`).

## Структура

| Шлях | Що там |
|------|--------|
| `projects/project-NN/starter/` | Відправна точка кожного проєкту (скопійовано з курсу). Тут я працюю. |
| `projects/shared/` | Спільна Electron + TS + React основа |
| `notes/` | Конспекти лекцій українською + відповіді на вправи |
| `PROGRESS.md` | Де я зараз, що зроблено, що далі |
| `CLAUDE.md` | Правила для агента в цьому репо (і водночас перший приклад harness) |

Еталонні `solution/` навмисно не скопійовані — дивлюся їх в оригінальному репо лише після власної спроби.

Лекції читаю тут: `docs/uk/lectures/` в оригінальному репо.
